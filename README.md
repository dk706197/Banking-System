# Banking System – Mini Project

## Project Overview

A Python-based mini project that simulates basic banking operations through a menu-driven application.

## Features

- Create a bank account
- Generate a unique account number
- Login using account number and PIN
- Check account balance
- Deposit money
- Withdraw money
- Transfer money between accounts
- View transaction history
- Change PIN
- Logout

## Python Concepts Used

- Variables and data types
- Conditional statements
- Loops
- Functions
- Lists and dictionaries
- String operations
- Modules

## Modules Used

- `random` – generates account numbers
- `datetime` – records transaction date and time

## How to Run

1. Install Python 3.
2. Open a terminal in this folder.
3. Run:

```bash
python banking_system.py
```

## Important Note

This is an educational mini project. Account data is stored in memory while the program is running. Closing the program clears the data.

## Project Flow

Create Account → Account Number + PIN → Login → Account Menu → Logout → Main Menu
